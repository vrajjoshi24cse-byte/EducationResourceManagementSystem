EDUCATION RESOURCE MANAGEMENT SYSTEM

Developed using Python and Tkinter.

FILES:
1. main.py - Main GUI application.
2. data_manager.py - Data handling and file storage.
3. reports.py - Charts and reports.
4. requirements.txt - Required libraries.

FEATURES:
- Add, update and delete resources.
- Track resource availability.
- Issue and return books or equipment.
- Save records in JSON files.
- Generate resource quantity charts.
- Generate usage reports.

HOW TO RUN:

Step 1: Install Python.

Step 2: Install libraries:
python -m pip install -r requirements.txt

Step 3: Run:
python main.py

Resource and issue records are saved automatically.
